PANDUAN INSTALL AUTOMATION DI MACBOOK (macOS)
============================================

1. INSTALL XCODE COMMAND LINE TOOLS
   xcode-select --install

2. INSTALL NODE.JS DARI WEBSITE RESMI
   - Buka: https://nodejs.org
   - Download versi LTS untuk macOS.
   - Install file .pkg.
   - Cek:
     node -v
     npm -v

3. COPY / CLONE PROJECT
   mkdir -p ~/projects
   cd ~/projects
   cp -r /Users/<username>/Documents/automation-flagging-taspen .
   cd automation-flagging-taspen

4. INSTALL PACKAGE PROJECT
   npm install

   Coba install browser Playwright:
   npx playwright install chromium

   Jika muncul error:
   "Playwright does not support chromium on mac13"
   maka pakai Google Chrome sistem:
   - Install Google Chrome dari https://www.google.com/chrome/
   - Script otomatis memakai Chrome di macOS, jadi tidak perlu set BROWSER_CHANNEL.
   - Lewati `npx playwright install chromium`

5. SETUP .ENV
   cp .env.example .env
   nano .env

   Isi:
   FLAGGING_LOGIN_URL=https://flagging.taspen.co.id/login
   FLAGGING_USERNAME=...
   FLAGGING_PASSWORD=...
   HEADLESS=false

6. FILE INPUT NOPEN
   Edit file:
   data/nopen.xlsx

   Isi kolom NOPEN, contoh:
   06005121500
   01011707900

7. JALANKAN
   npm run test

8. HASIL
   File hasil:
   reports/hasil-booking.xlsx

   Kolom hasil:
   - NOPEN
   - Nilai
   - Status (Berhasil / Tidak Booking / Tidak Ditemukan)

9. SESSION LOGIN
   - Run pertama butuh OTP manual.
   - Session disimpan ke auth.json.
   - Jika session expired, hapus auth.json lalu jalankan ulang.
